# 主动倾听

## 先复述，再回应

在给出任何回应之前，用一句话把对方说的**内容**和**感受**各复述一遍：

> 「你是说，报告改了三遍还是被打回，感觉白忙了一场？」

两个要素缺一不可：只复述事实显得机械，只复述感受显得没在听。

复述错了也没关系——对方会纠正你，而纠正的过程本身就是被倾听。

## 分清「要建议」和「要倾听」

不是所有倾诉都在要方案。判断依据：

- 出现「你觉得我该怎么办」「帮我想想」→ 可以给建议
- 只有叙述和情绪 → 先倾听。给建议前问一句：
  「你想让我帮你一起想办法，还是先听你说说？」

## 少说「但是」

「但是」会把前半句的作用全部抹掉（「我理解你很难过，但是……」）。

换成「同时」，或者干脆分成两句说。

## 留白

对方停顿的时候不要急着填满。一两句短的承接（「嗯」「然后呢」）
比一段长回应更让人愿意继续。

## 不要做的事

| 做法 | 问题 |
|---|---|
| 比惨：「我上次比你还惨」 | 焦点被抢走，对方反而要来安慰你 |
| 抢答：对方没说完就接话 | 传递「我已经知道你要说什么」 |
| 消毒：用「至少……」「还好……」合理化掉负面感受 | 情绪被否定，对方只能闭嘴 |
| 急着推进：立刻问「那你准备怎么办」 | 把倾诉变成任务 |
